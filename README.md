## ✨ 핵심 가치 제안 (Why Picky.AI)

- **프롬프트 입력만으로 상세페이지 완성**
- **이미지·영상·텍스트 올인원 자동화**  
  → 합성 이미지, 홍보 영상, 설명문, 리뷰, 정책까지 한 번에 생성
- **모든 상품군 적용 가능** (패션, 리빙, 뷰티, 전자제품 등)
- **제작 시간 90%+ 단축**: 기획·디자인·카피라이팅 부담 최소화
- **데이터 관리·배포 자동화**: Supabase 기반 DB/스토리지 + PDF/PNG/ZIP Export

### 2) 01. 창업 배경 및 문제 인식 (Background)

<img src="./images/03.PNG" width="940" />

- 온라인 쇼핑몰 수는 늘었지만 **1년 내 폐업률 30%**  
- 문제 원인:
  - 시장 포화
  - 인력 부족(디자인·촬영·마케팅)
  - 제작 비용 부담  
- → AI 자동화를 통해 **제작·운영의 벽을 낮추는 것**이 목표

### 3) 02. 솔루션 개요 — Picky.AI

<img src="./images/04.PNG" width="940" />

> **Picky.AI = AI 기반 상세페이지 자동 제작 솔루션**

- **상품 이미지 기반, 상세페이지 자동 생성·보정**
- **텍스트·설명문 자동 작성** (키워드 분석 + GPT)
- **구성·배치 자동화**: AI와 사람이 함께 편집하는 콜라보 구조

---

### 4) 03. 카페24 & 스마트스토어 등과 연동

<img src="./images/05.PNG" width="940" />

- 카페24·스마트스토어 등 **주요 쇼핑 플랫폼과 연동**
- 한 번의 승인/클릭으로:
  - 상세페이지 → 각 쇼핑몰 상품 등록 화면에 자동 반영
  - 운영자의 **반복 업로드 작업 최소화**

---

### 5) 04. 상담 어드바이스 챗봇

<img src="./images/06.PNG" width="940" />

- AI 챗봇이 고객 문의를 실시간으로 처리
- 상담원 화면에 **자동 제안 문장(어드바이스)** 제공
- 최근 상담 내역 요약, 감정 분석 등을 통해
  - 응대 품질 향상
  - 상담 시간 단축

---

### 6) 05. 시연동영상 (Feasibility)

<img src="./images/07.PNG" width="940" />

- 실제 **프로토타입 웹 화면** 기반 시연
  - 왼쪽: GPT 기반 프롬프트/대화 영역
  - 오른쪽: 상품 이미지 업로드 및 분석 결과
- AI가 이미지와 텍스트를 조합해
  - 상품 분석
  - 설명문
  - 상세페이지 초안을 자동 생성하는 모습 확인 가능

### 7) 06. 왜 이 솔루션이 필요한가 (시장 데이터)

<img src="./images/08.PNG" width="940" />

- 출처: 경기소상공인 경제이슈 브리프(2024)  
- **디지털·AI 기술 서비스 도입을 막는 이유**
  - 도입 비용 부담
  - 해당 기술에 대한 정보 부족
- Picky.AI는:
  - **저렴한 API 원가**
  - 쉬운 사용성으로
  - 소상공인도 **부담 없이 시작**할 수 있는 구조를 제안

---

### 8) 06-2. 왜 이 솔루션이 필요한가 (제작비/시간 관점)

<img src="./images/09.PNG" width="940" />

- 현재 상세페이지 외주비: **12만 ~ 42만 원/건**
- Picky.AI 적용 시:
  - GPT 호출 6회 (요약, 설명 4회, 스토리 1회)
  - 이미지 생성 5회 (DALL·E 또는 Runway 기준)  
  → **API 원가 약 2원/건 수준**으로 완전 자동화 가능  
- “아이디어는 많지만 제작비가 장벽인” 상황을 해소

### 9) 07. 시스템 작동 방식 (System Flow)

<img src="./images/10.PNG" width="940" />

1. **상품 정보 입력**  
   - 이름, 카테고리, 스타일 등 기본 정보 입력  
2. **AI 이미지 생성**  
   - 실제 촬영처럼 보이는 고품질 합성 이미지 자동 생성  
3. **자동 배치 & 템플릿 적용**  
   - 텍스트·이미지를 브랜드 맞춤형 템플릿에 즉시 배치  
4. **플랫폼 업로드**  
   - 카페24·스마트스토어 등 주요 쇼핑몰에 자동 업로드

## 🧩 주요 기능

1. **상품 상세페이지 자동 생성**  
   - 프롬프트 기반: 상품명/특징 입력 → 이미지+설명문+정책 자동 생성  
   - 모델 합성 이미지 다수 + 다각도 컷 자동 구성  
   - GPT 기반 스토리/스펙표 자동 작성  

2. **홍보 영상 생성**  
   - Runway API → 업로드 이미지 + 프롬프트 → 상품 영상 자동 제작  

3. **정책·리뷰 자동화**  
   - 배송/교환/환불 정책 초안, 리뷰 문구, FAQ 자동 생성  

4. **템플릿 적용 & Export**  
   - Modern/Basic 등 템플릿 선택 → Preview  
   - PDF/PNG/ZIP Export → 입점 제안서, 상세페이지, 보고서 활용  

5. **Supabase 연동**  
   - DB 저장: prompt/결과 데이터, 이미지 URL  
   - Storage: detail-images 버킷 → public URL 활용

## 🚀 실행 방법 (Local)

### 1) 환경 변수 설정

**server/.env**
```bash
OPENAI_API_KEY=...
SUPABASE_URL=...
SUPABASE_SERVICE_ROLE_KEY=...
RUNWAY_API_KEY=...
```

**client/.env**

```bash
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
VITE_API_BASE=http://localhost:8080
```

### 2) 설치 & 실행

```bash
# server
cd server && npm install && npm run dev
# client
cd client && npm install && npm run dev
```

* 프론트엔드: [http://localhost:5173](http://localhost:5173)
* 백엔드: [http://localhost:8080](http://localhost:8080)
